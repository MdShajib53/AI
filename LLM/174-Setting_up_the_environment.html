Setting up the environment

1. Creating a new Python environment

Just like with the NLP module, we’ll set up a separate virtual environment for the LLM part of the course. This ensures that all libraries are installed with the correct versions and won’t interfere with other projects on your system.

We’ll use conda to manage the environment:

conda create --name llms_course_env python=3.11

conda activate llms_course_env

Once activated, you’ll see (llms_course_env) appear before your command line prompt.

2. Installing the relevant packages

Now we’ll install all the libraries needed for the LLM module using pip.

Run the following commands inside the activated environment:

pip install openai==0.28 config==0.5.1 langchain==0.0.297 pydantic==1.10.9 tiktoken==0.5.1 faiss-cpu==1.7.4 transformers==4.47.1 torch==2.5.1 datasets==3.2.0 evaluate==0.4.3 accelerate==1.2.1 ipywidgets==8.1.5 matplotlib==3.10.0 seaborn==0.13.2 clean-text==0.6.0 scikit-learn==1.6.0 sentencepiece==0.2.0 pandas==2.0.0

We’ll also add Jupyter support so you can run notebooks with this environment:

pip install ipykernel jupyterlab notebook

python -m ipykernel install --user --name=llms_course_env

When you open Jupyter Notebook or Lab, make sure the kernel is set to llms_course_env.

3. Explaining the packages

Here’s what each library does and why we’ll need it:

  • openai (0.28) – Official client library to interact with OpenAI’s GPT models and APIs.

  • config (0.5.1) – A lightweight configuration manager for storing and loading project settings.

  • langchain (0.0.297) – A framework for building applications powered by LLMs. It helps you chain prompts, connect to vector databases, manage agents, and orchestrate complex workflows.

  • pydantic (1.10.9) – Used for defining and validating data models, ensuring inputs and outputs of LLM pipelines are structured correctly.

  • tiktoken (0.5.1) – A tokenizer optimized for OpenAI models. It helps count tokens and split text in the exact way models process input.

  • faiss-cpu (1.7.4) – A vector database library for efficient similarity search and retrieval, commonly used for embedding-based LLM applications (e.g., question answering over documents).

  • transformers (4.47.1) – Hugging Face’s library with pretrained transformer models (BERT, GPT, etc.) for fine-tuning and inference.

  • torch (2.5.1) – The PyTorch deep learning framework that underlies transformers and custom neural network work.

  • datasets (3.2.0) – Provides large NLP and ML datasets with efficient streaming and preprocessing.

  • evaluate (0.4.3) – A companion library for datasets that makes it easy to compute metrics (accuracy, BLEU, F1, etc.) for model evaluation.

  • accelerate (1.2.1) – Simplifies training large models across CPUs, GPUs, or multiple devices.

  • ipywidgets (8.1.5) – Adds interactivity to notebooks with sliders, buttons, and dropdowns, useful for testing LLM parameters.

  • matplotlib (3.10.0) – Core plotting library for visualizing results.

  • seaborn (0.13.2) – Higher-level plotting library for statistical visualizations with cleaner styling.

  • clean-text (0.6.0) – A utility for cleaning and normalizing messy text (removing special characters, HTML, etc.) before feeding it into models.

  • scikit-learn (1.6.0) – General ML toolkit for feature engineering, clustering, or evaluating model performance.

  • sentencepiece (0.2.0) – A tokenizer often used in LLMs like T5 and GPT. It handles subword units for more flexible text modeling.

  • pandas (2.0.0) – Essential for handling and analyzing structured datasets in tabular format.
